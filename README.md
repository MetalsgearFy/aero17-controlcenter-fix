# AERO 17-XA 控制中心一键修复安装器

> 适用于 **GIGABYTE AERO 17-XA**（Intel Core i7-9750H）控制中心打不开 / 键盘卡顿问题的**一键修复安装包**。

## 适用机型与配置

- 本修复包由 **GIGABYTE AERO 17-XA** 实机验证，实测配置：
  - CPU：Intel Core **i7-9750H**（第 9 代酷睿 H 系列）
  - GPU：NVIDIA GeForce **RTX 2070 Max-Q**
  - 控制中心版本：22.12.20.01（配套 XTU 7.5.3.3）
- **为什么同款/同代都可能遇到**：问题根源是控制中心依赖的 **Intel XTU 组件版本错配**，与具体型号无关，而与使用的 CPU 平台和控制中心版本相关。
- **同一款机型，或采用同代 CPU（Intel 第 9 代酷睿 H 系列，如 i7-9750H / i7-9850H / i5-9300H / i9-9880H 等）且使用同版本控制中心的技嘉笔记本，都可能遇到同样问题**，可直接使用本安装器修复。
- 其他机型 / 其他代 CPU：请先核对你的控制中心版本与其配套的 XTU 版本（参考仓库内《AERO17控制中心解决与重装指南.md》），确认配套关系后再使用本安装器。

## 这是什么问题？

技嘉原厂控制中心（Control Center 22.12.20.01）依赖配套的 Intel XTU（Intel Extreme Tuning Utility）**7.5.3.3** 进行 CPU 调参通信。

如果系统里残留了**其他版本**的 XTU（例如 7.14.2.14），控制中心与 XTU 服务通信时会发生数据解析异常，导致：

- ControlCenter.exe 启动即崩溃（`IronCity.Core.IXtuTuning.ProposeChange` / `FormatException` / `NetDispatcherFaultException`）
- 键盘输入异常卡顿（XTU 服务异常时影响系统级输入处理）

原厂安装包**不会**自动卸载系统里已有的新版 XTU，这就是重装后仍然打不开的根源。

## 本安装器做了什么

双击运行后自动完成：

1. **检测**系统内 Intel XTU 版本（只读检查）
2. **卸载**不配套的旧版本（如 7.14.x，会先弹窗确认）
3. **静默安装**配套版本 **7.5.3.3**（原厂 Intel 签名文件）
4. **运行技嘉原厂控制中心安装包** 22.12.20.01（走原厂安装向导）
5. 提示**重启**，使全部组件生效

内置的两个组件文件均为技嘉 / Intel 原厂签名文件，安装器不修改任何系统安全设置，不注入补丁。

## 使用方法

1. 右键 → **以管理员身份运行** `AERO17_ControlCenter_Fix_Setup.exe`
2. 点击“下一步”，查看 XTU 检测结果
3. 如检测到不配套版本，点击“是”自动卸载
4. 跟随 XTU 静默安装 → 控制中心原厂向导完成安装
5. 重启 Windows
6. 从开始菜单打开 Control Center，验证风扇、键盘背光与 CPU 调参功能

> 重装系统后也可直接使用本安装器完成“控制中心 + 配套 XTU”的一次性安装。
